# Visual Guide to New Layouts

## 1. Drawer + Main
![Drawer + Main Layout](URL_to_diagram_1)
This layout features a side drawer that allows users to navigate between different sections of the application while viewing the main content area.

## 2. Breadcrumb Navigation
![Breadcrumb Navigation Layout](URL_to_diagram_2)
The breadcrumb navigation helps users keep track of their location within the application, providing an easy way to navigate back to previous sections.

## 3. Top Tabs
![Top Tabs Layout](URL_to_diagram_3)
Top tabs provide quick access to different views or sections of the application, utilizing a horizontal tab layout for easy navigation.

## 4. 3-Column Layout
![3-Column Layout](URL_to_diagram_4)
The 3-column layout organizes content into three distinct columns, allowing for a structured presentation of information.
